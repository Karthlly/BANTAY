# BANTAY
### A Web-Based Epidemiological Surveillance and Decision Support System for the Calapan City Health Office

##  About
BANTAY (Barangay-based Analysis of Notifiable Diseases for Tracking, Alerting, and Yielding Decision Support) is a capstone project that aims to support disease surveillance and public health decision-making through data analytics and web technology.

##  Key Features
- **Data Validation** – Detects duplicate records, missing data, invalid ICD-10 codes, and incorrect barangay names.
- **Interactive Dashboard** – Displays disease cases, demographics, and trends.
- **Barangay Monitoring** – Visualizes disease distribution across barangays.
- **Surveillance Alerts** – Uses configurable rules to identify potential outbreak situations.
- **Report Generation** – Supports epidemiological reports in PDF and Excel formats.
- **Role-Based Access** – Supports Administrator, Surveillance Officer, Health Officer, and Viewer roles.

##  Workflow
1. Upload de-identified datasets exported from iClinicSys.
2. Validate and standardize records.
3. Analyze disease cases and trends.
4. Evaluate surveillance rules and generate alerts.
5. View dashboards and generate reports.

##  Scope
BANTAY is designed to complement iClinicSys, not replace it. Data must be exported and uploaded manually. The system uses descriptive analytics and rule-based alerts; it does not perform machine-learning-based outbreak prediction. Alerts support surveillance and do not constitute official outbreak declarations.
